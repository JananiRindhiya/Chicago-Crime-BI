# Chicago Crime BI

A Power BI and machine-learning project for analyzing Chicago crime data.

## Contents

- `Chicago_Crime_BI_Ensemble.ipynb` — Jupyter notebook containing the ensemble/ML analysis.
- `Chicago_Crime_BI_PBIP/` — Power BI Project (PBIP) containing the report and semantic model definitions.
- `powerbi_data/` — Data generated/used by the project, including cleaned crime data, predictions, confusion matrices, model comparison, and feature importance.

## Power BI Project

Open `Chicago_Crime_BI_PBIP/Chicago_Crime_BI.pbip` in Power BI Desktop with PBIP support enabled.

## Data Files

The `powerbi_data` folder contains:

- `crime_cleaned.csv`
- `crime_predictions.csv`
- `confusion_matrices.csv`
- `model_comparison.csv`
- `feature_importance.csv`

## Repository Notes

This repository contains the project source files rather than a `.pbix` file. The PBIP folder structure should be preserved when opening or editing the Power BI project.
